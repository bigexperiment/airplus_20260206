## ⚡ Get Started in 3 Steps

### 1️⃣ Install
```bash
npm install
```

### 2️⃣ Run
```bash
npm start
```

### 3️⃣ Open
```
http://localhost:4200
```

## 🎯 What Can You Do Right Now?

### 🌐 Explore the Public Website
- **Home** - Beautiful landing page
- **Treks** - Browse and filter treks
- **Trek Details** - View details and book
- **About** - Company information
- **Contact** - Get in touch

### 🔐 Try the Admin Dashboard
1. Go to: `http://localhost:4200/admin/login`
2. Login with:
   - Username: **admin**
   - Password: **admin**
3. Manage:
   - ✅ Treks (Create, Edit, Delete)
   - ✅ Bookings (View, Update Status)
   - ✅ Categories (CRUD)
   - ✅ Users (Admin only)
